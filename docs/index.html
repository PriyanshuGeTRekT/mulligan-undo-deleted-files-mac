Recently deleted

Get back anything you deleted.

Every file in the folders you protect is copied the moment it changes. Delete it with rm, empty the Trash, or let an app remove it: it is still one click away.

  • Restores byte for byte, with the original date.
  • Never overwrites: if something lives at the old path, the copy lands next to it.
  • Recoverable for 30 days by default.
  • Moving files into the Trash is shown as “moved out”, not as lost.

Mass-deletion alarm

Notices when files vanish by the dozen.

A script, an app or an AI agent deletes a whole folder. Mulligan raises one alert, not hundreds, with a single Restore all button.

  • Renames and moves are recognised and never trigger it.
  • Short-lived temp files don’t count.
  • A notification, even when the menu is closed.

Every version

Go back to an earlier version.

Saved over the wrong file? Search by name, open the file and pick the version you want.

  • Everything for 24 hours, hourly for a week, daily after that.
  • Search live and deleted files together.
  • Restore a whole folder as it was at any time.

Command line

Undo what a script or AI agent did.

Wrap any command, agent session or script in mulligan run. Afterwards it tells you exactly what changed, and one command puts it all back.

  • mulligan deleted, find, history, restore, restore-tree --deleted.
  • Works with Claude Code, Codex, Cursor or any shell command.
  • --json output for scripts.
$ mulligan run -- ./cleanup.sh
mulligan: `cleanup.sh` finished. In your protected folders it:
   deleted   212 files
   modified    9 files
   Undo it with:  mulligan undo-run 7

$ mulligan undo-run 7 --yes
restored 221 files

Disk space

Costs almost nothing.

APFS clones share disk blocks with your files. Only what changes or gets deleted takes space, and Mulligan gives space back automatically when your disk gets tight.

  • 60,000 files protected in 11 seconds using 46 MB.
  • A space budget (10% of the disk, at most 50 GB).
  • Excluded from Time Machine and Spotlight.

Up and running in a minute.

Requires macOS 14 or later on a Mac with Apple silicon.

  1. Download

    Download Mulligan.zip, unzip it and drag Mulligan.app into your Applications folder.

    Or install it with Homebrew:

    brew install --cask priyanshugetrekt/mulligan/mulligan

    Run the brew tap command shown at the top of the page first.

  2. Open Anyway

    Mulligan is not notarized by Apple, so macOS blocks the first launch. Open System Settings › Privacy & Security, scroll down and click Open Anyway next to Mulligan.

    You only need to do this once.

  3. Get started

    The first time it opens, Mulligan asks which folders to protect, and macOS asks whether it may access Desktop, Documents and Downloads. Choose Allow.

Prefer to build it yourself? Build from source with just the Command Line Tools.

Questions and answers.

How do I recover a file I deleted with rm on Mac?

If Mulligan was protecting the folder, open Mulligan’s Deleted tab and click Restore, or run mulligan restore with the file’s path. rm skips the Trash, so without a copy like this the file is gone.

Can I get files back after emptying the Trash on Mac?

Yes, if they were in a folder Mulligan protects: Mulligan kept a copy when the file was created or changed, so emptying the Trash doesn’t matter.

How do I undo what an AI coding agent deleted?

Run the agent through mulligan run -- your-command. Afterwards Mulligan lists what was deleted and changed, and mulligan undo-run puts it all back. The menu-bar app also alerts you when many files vanish at once.

Is Mulligan a backup?

No. The copies live on the same disk, so a dead or stolen Mac takes them along. Keep Time Machine or a cloud backup too; Mulligan covers the everyday accidents those are slow at.

Does Mulligan use a lot of disk space?

No. It uses APFS clones, which cost nothing until a file changes or is deleted. Deleted files keep their space until they expire (30 days by default) or until your disk gets low, when Mulligan gives the oldest back first.

Why does macOS say Mulligan cannot be opened?

Mulligan is not notarized by Apple, so macOS blocks the first launch. Open System Settings › Privacy & Security, scroll down and click Open Anyway next to Mulligan. You only need to do this once.

Is Mulligan free and safe?

Yes. It is free and open source under the MIT License. It makes no network requests, has no account, and only ever writes inside its own folder, except when you restore a file.
